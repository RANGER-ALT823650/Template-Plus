# 底图来源

2026-09-30 从相邻 `iPhone-Air/output/` 复制 `iphone-air-plateau-cutout.svg`、`dimensions.json` 和 `sticker-designs/placements.json`，原文件未修改。`src/plateau.js` 使用此 SVG 的精确路径及 dimensions.json 的毫米尺寸、孔位和 2 mm PDF 页面边距。

几何来源：Apple iPhone Air Dimensional Drawings，图纸日期 2025-09-09。
https://developer.apple.com/download/files/accessories/dimensional-drawings/iphone-air.pdf

原始来源 PDF 与完整来源说明仍保存在相邻 `iPhone-Air/sources/` 和 `iPhone-Air/README.md`。背面正视、手机顶部向上、镜头在左，不镜像。平台顶部平面宽高属于工程图轮廓推导值，孔位和直径按原数据，工艺补偿为 0。
