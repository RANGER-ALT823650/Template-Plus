# iPhone Air 背面效果机模

四种官方配色：天蓝色、深空黑色、云白色、浅金色。
官方尺寸：74.7 × 156.2 mm。来源： https://www.apple.com.cn/iphone-air/specs/

`*-rear.svg` 是背面正视示意机模，镜头在左、不镜像。按官方机身尺寸绘制，平台外轮廓、三孔和平台原点沿用 Plus 的 Apple 工程图派生数据。平台原点为机身左上角 (4.7722330227, 4.5274593124) mm，三孔中心换算后分别为官方机身坐标 (16.29,16.29)、(51.34,16.29)、(58.42,16.29) mm。

机身圆角、材质高光、镜片与色泽为预览示意；颜色是参考 Apple 产品图片的屏幕近似，没有官方 RGB 数值或印刷色彩保证。四张 `*.png` 是未修改的官方产品参考图片，并非正视背面；下载来源保存在 `sources.json`。官方 logo 轮廓取自 Apple 导航 SVG。生成脚本为 `scripts/build-mockups.mjs`。

实时贴纸通过共享 `renderDesignSVG` 渲染，以毫米原点叠加机模；灰底、刀线及编辑控制点均不叠入整机。整机仅参与屏幕预览，不进入 PDF / SVG / PNG 印刷输出或布局对象。
