# Pro / Pro Max 平台与机模

独立保存在 Template-Plus；未改动相邻 iPhone-Air 或 Template。

- `sources/`：Apple 17、18 Pro / Pro Max 原始工程 PDF，下载于 2026-09-30。
- `previews/`：工程图第 1 / 3 张图及 Detail D 的核对预览。
- 各机型目录：`plateau-cutout.svg` 为灰底透明挖孔底图；`dimensions.json` 保留来源、校准、矢量索引、机身尺寸、推导平台尺寸、六个标称孔和原图 SHA-256。
- `mockups/`：各代官方配色的背面示意 SVG，RGB 与外观为近似，机身与孔位采用尺寸 JSON；不进入成品导出。

提取与复现说明见项目 README。平台轮廓是官方矢量推导值；18 Pro 右下轮廓使用完整左侧片段对称重建。尚未加入加工余量，实裁前按 1:1 纸样核对。
